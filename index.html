Functional Memory of Low-rank Subspaces

Trained low-rank adapters (LoRAs) record what a model has learned from completed tasks. FML continually consolidates this task experience into a shared functional memory that preserves past solutions and provides reusable structure for future adaptation.

Each incoming adapter is reconstructed in the accumulated basis and rescaled. Predictions on unlabelled task inputs guide the addition of residual directions, while previously admitted reconstructions remain unchanged. The resulting memory supports target-data-free LoRA initialization and description-conditioned generation, with further coefficient adaptation within the frozen basis.

Functional capture and preservation

Functional capture and the global scale

\[ C_t = 1-\frac{\mathbb{E}_{x}\,\mathrm{KL}\big(p_t\,\|\,\widehat p_t\big)}{\mathbb{E}_{x}\,\mathrm{KL}\big(p_t\,\|\,p_0\big)} \qquad \alpha_t=\sqrt{\frac{\sum_m \lVert \Delta W_{t,m}\rVert_F^2}{\sum_m \lVert \widetilde{\Delta W}_{t,m}\rVert_F^2}} \]

Functional capture measures recovery relative to the base model. Admission checks both capture and residual KL.

Preservation of admitted reconstructed updates

\[ \begin{bmatrix} U_B & D_B \end{bmatrix} \begin{bmatrix} G_t & 0 \\ 0 & 0 \end{bmatrix} \begin{bmatrix} U_A & D_A \end{bmatrix}^{\top} = U_B\,G_t\,U_A^{\top} \]

Appending basis directions and zero-padding stored coefficients leaves each admitted reconstructed update unchanged.

Functional re-ranking

Re-ranking concentrates cross-task usage in leading directions while preserving the represented updates.

Target-data-free LoRA initialization

FML-Init uses globally ranked memory directions to initialize a new LoRA without target inputs. After 256 updates, it reaches 73.4 ± 1.0 mean ROUGE-L, compared with 71.8 ± 1.0 for rank-4 LoRA. Results are averaged over five held-out SNI tasks and three seeds.
